# STAG-1

STAG-1 is an open-source rocketry data logging and flight computer based around the Pi Pico microcontroller. The flight computer will measure, log and transmit live data during its flight on the rocket’s attitude, position and environment. 

The project will provide students with hands-on experience working with rocketry and flight avionics and electronic systems.

# Getting Started

The Stag-1 is centred around the Raspbeery Pi Pico, which can be coded using the Arduino IDE, The Raspberry Pi Pico C/C++ SDK and Micropython.
This projecct will be using the Arduino IDE to code the STAG-1 flight computer as it is a free open-source program very user and beginner friendly.

Download the Arduino IDE 2.X [here](https://docs.arduino.cc/learn/starting-guide/the-arduino-software-ide/) and follow the setup guide:
